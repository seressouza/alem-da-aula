# Além da Aula · Cirurgia Cardíaca

Trilha de aprendizagem que acompanha a aula "Da admissão à alta hospitalar".
App web instalável (PWA): depois do primeiro acesso com internet, funciona offline.

## Arquivos
- index.html: o app inteiro (conteúdo, demonstrações e quizzes)
- sw.js: guarda o app e o PDF para uso offline
- manifest.webmanifest, icon-192.png, icon-512.png: instalação na tela inicial
- aula.pdf: o PDF da aula (adicione o seu, com exatamente este nome)

## Atualizar o app
Depois de editar qualquer arquivo, abra sw.js e troque `trilha-v1` por `trilha-v2` (e assim por diante).
Isso faz os celulares baixarem a versão nova.
